# Security

ClearCe runs an explicitly selected local AI executable. Only choose trusted distributions. Integrity hashes detect changes; they do not authenticate publishers or sandbox filesystem/network access.

Do not put credentials, private images, personal paths or exploit details in public issues. Use GitHub private vulnerability reporting if enabled. Otherwise ask the maintainer for a private channel without publicly disclosing the vulnerability. No security mailbox or response-time guarantee is configured.

Version 0.1.0 is unsigned. Cleanup rejects reparse points and unowned paths, but the app is not a security boundary against a hostile process running as the same Windows user. Phase reports record verification limits.
