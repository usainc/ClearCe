# Security

ClearCe runs an explicitly selected local AI executable. Only choose trusted distributions. Integrity hashes detect changes; they do not authenticate publishers or sandbox filesystem/network access.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/usainc/ClearCe/security/advisories/new). Do not put credentials, private images, personal paths, exploit details or undisclosed vulnerabilities in public issues. No security response-time guarantee is currently offered.

Version 0.1.0 is unsigned. Cleanup rejects reparse points and unowned paths, but the application is not a security boundary against a hostile process running as the same Windows user. Phase reports record verification limits.
